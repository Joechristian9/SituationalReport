# Situational Report — Design System (MASTER)

Source of truth for UI in `resources/js`. Page-specific deviations go in `design-system/situational-report/pages/<page>.md` and override this file.

Built by hand from the existing stack (shadcn "new-york", Tailwind 3, Figtree, lucide) and the `ui-ux-pro-max` Quick Reference. It is **not** generated by the skill's search script (Python was unavailable), so re-run `--design-system` later if you want data-driven alternatives.

## 1. Product & direction
- **Product:** disaster situational reporting for CDRRMO staff and barangay accounts. Operational, data-dense, used under stress and often on phones in the field.
- **Style:** clean, flat, high-clarity "operations console". Light mode default, dark mode supported. No glassmorphism, gradients, or decorative motion.
- **Principles:** status first (disaster state always visible), clarity over decoration, one primary action per screen, never rely on color alone.

## 2. Current-state findings (why this exists)
- `app.css` tokens are default shadcn grayscale, so `bg-primary` renders near-black.
- Pages bypass tokens: ~130× `text-blue-600`, plus `bg-blue-50/600`, `border-blue-500`, and a mix of `gray-*` and `slate-*` for the same job.
- Rule going forward: **components use semantic tokens, not raw palette classes.** Migrate pages gradually (see §10).

### Semantic status mapping
| Meaning | Token | Pair with (never color alone) |
|---|---|---|
| Disaster **active** | `success` | dot + "Active" |
| Disaster **paused** | `warning` | pause icon + "Paused" |
| Disaster **ended** | `muted-foreground` | check icon + "Ended" |
| Error / destructive / casualty counts | `destructive` | alert icon + text |
| Informational / selected | `info` / `primary` | label |
Status chips: `bg-<token>/10 text-<token> border-<token>/30` + icon + text.

## 4. Typography
- **Font:** Figtree (already loaded, weights 400/500/600). Add `font-variant-numeric: tabular-nums` (`tabular-nums` class) for every number column, count, and timer.
- **Scale (px):** 12 caption · 14 body-dense/table · 16 body/forms · 18 section · 24 page title · 32 hero stat. Inputs and mobile body text are **16px minimum** (prevents iOS zoom).
- Weights: 600 headings, 500 labels, 400 body. Line-height 1.5 body, 1.25 headings. Max line length 75ch.
- Headings sequential `h1→h6`; one `h1` per page.

## 5. Spacing, shape, elevation
- 4px base grid; use Tailwind steps 1/2/3/4/6/8/12. Section gap 24, card padding 16 (mobile) / 24 (desktop), table cell `px-3 py-2`.
- Radius: `--radius` 8px (cards, inputs), `rounded-full` only for badges/avatars.
- Elevation: `border` + `shadow-sm` for cards; `shadow-md` popovers; `shadow-lg` dialogs. No other shadows.
- Container: content `max-w-7xl`, page gutter `px-4 sm:px-6 lg:px-8`. Use `min-h-dvh`, not `100vh`.
- Z-index scale: 0 content · 10 sticky header · 20 sidebar · 40 dropdown/popover · 50 dialog · 100 toast.

## 6. Responsive
- Mobile-first breakpoints: 375 · 768 (`md`) · 1024 (`lg`) · 1440 (`2xl`). No horizontal page scroll.
- Sidebar (≥1024px) collapses to the `Sheet` drawer below; top-level nav only, active item highlighted.
- Tables: wrap in `overflow-x-auto` with sticky first column, or switch to stacked cards below `md` for forms/lists with ≤5 key fields.
- Forms: single column on mobile, 2 columns from `md`; input height ≥44px on touch (`h-11 md:h-9`).

## 7. Components (use existing `Components/ui`; adjust as listed)
| Component | Standard |
|---|---|
| **Button** | One `default` (primary) per view; others `outline`/`ghost`. Destructive uses `destructive` + confirm dialog. Min touch target 44px (add `min-h-11 md:min-h-9`). Show spinner + `disabled` while submitting. Icon-only buttons need `aria-label`. |
| **Input / Select / Textarea** | Visible `<Label>` (never placeholder-only); `border-input`; error text below field with `InputError` + `aria-describedby`; required marked `*`; helper text below. |
| **Table** | Sticky header, `tabular-nums` numeric columns right-aligned, zebra off (use hover `bg-muted/50`), sortable headers with `aria-sort`, empty state row with next action, skeleton while loading, pagination via `Pagination` + `RowsPerPage`. |
| **Badge/Status chip** | Per §3 mapping; text ≥12px; icon + text. |
| **Card / stat tile** | `bg-card border rounded-lg p-4`; label (muted, 14px), value (24–32px, tabular-nums), optional delta with icon. |
| **Dialog / Sheet** | Focus trapped, `Esc` closes, visible close button, confirm before dismissing unsaved forms. |
| **Toast** | Use `sonner` only; 3–5s; `aria-live=polite`; success/error with icon. |
| **Banner (`DisasterStatusBanner`)** | Always visible under header; shows status chip + disaster name; paused/ended states disable forms and say why. |
| **Charts (Recharts)** | Use `--chart-*` tokens; legend visible; tooltips; label axes with units; provide a table/summary alternative; pie only ≤5 slices. |
| **Icons** | `lucide-react` only (matches `components.json`), 16/20/24px tokens, 1.5–2 stroke, no emoji. Decorative icons `aria-hidden`. |

## 8. Interaction & motion
- Transitions 150–200ms on `color, background-color, opacity, transform` only. Exit ≈ 60–70% of enter. No animating width/height/top/left.
- Hover is never the only affordance; every clickable has `cursor-pointer` and visible `focus-visible:ring-2 ring-ring ring-offset-2` (current `button.jsx` uses `ring-1` — raise to 2).
- Respect `prefers-reduced-motion` (use `motion-reduce:transition-none`; disable framer-motion/entrance animations).
- Loading: skeleton for >1s, spinner in buttons; reserve space to avoid layout shift.

## 9. Accessibility checklist (must pass before merge)
- [ ] Text contrast ≥4.5:1, UI/icons ≥3:1, in **both** light and dark.
- [ ] Full keyboard operation; tab order = visual order; focus never hidden by sticky header/banner.
- [ ] Every input has a label; errors specific, adjacent, announced (`role="alert"`/`aria-live`); failed submit focuses first error or a summary.
- [ ] Color never the only signal (status, charts, required, errors).
- [ ] Touch targets ≥44px on mobile (≥24px absolute minimum on desktop); 8px gaps.
- [ ] Verified at 375px and landscape, with reduced-motion on, and with text zoom 200%.
- [ ] Destructive actions confirmed and visually separated.

## 10. Anti-patterns to remove (found in codebase)
- Raw `text-blue-600`, `bg-blue-50`, `border-blue-500`, `gray-*`/`slate-*` for the same role → replace with `text-primary`, `bg-accent`, `border-primary`, `text-muted-foreground`, `bg-muted`, `border-border`.
- `text-gray-400` on white for readable text (≈2.5:1, fails) → `text-muted-foreground`.
- Placeholder-only labels, icon-only buttons without `aria-label`, hover-only actions.
- Two toast libraries (`sonner`, `react-hot-toast`) → standardize on `sonner`.
- Duplicate layout files (`AuthenticatedLayout copy.jsx` already removed).
